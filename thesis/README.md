# Thesis Writing

This directory is the home for everything related to producing the final Master's thesis **document** — as opposed to `docs/`, which holds research notes, experiment plans, and progress logs, and `research/`, which holds literature/reading material. Once manuscript writing begins, the LaTeX project (chapters, preamble, figures, bibliography) will live here.

## Current status

Analysis only — no manuscript scaffolding has been created yet. The author's bachelor thesis (Overleaf export, extracted at `resources/Thesis_Bachelor/`) was reviewed as a reference point, since the Master's thesis is expected to reuse the same institutional conventions, LaTeX template, and overall document structure, adapted for a different topic (embedded wildlife detection vs. the bachelor thesis's small-object car detection) and Master-level scope.
