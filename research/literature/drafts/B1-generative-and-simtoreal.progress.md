## sec:lit_generative_models (Generative Models for Image Synthesis)
- [x] goodfellowGenerativeAdversarialNetworks2014 — GAN, adversarial minimax framework. Read in full: minimax game between generator G and discriminator D, no Markov chains, global optimum at p_g=p_data (Jensen-Shannon divergence = 0).
- [x] radfordUnsupervisedRepresentationLearning2016 — DCGAN. Read in full: architectural constraints for stable conv GAN training (strided convs replacing pooling, batchnorm, ReLU/LeakyReLU, no FC layers); demonstrated learned representations useful for downstream classification (CIFAR-10, SVHN) and latent-space vector arithmetic.
- [x] karrasStyleBasedGeneratorArchitecture2019 — StyleGAN. Read (OCR garbled but decipherable): style-based generator maps latent z through mapping network to intermediate latent space W, controls synthesis via AdaIN per layer at each resolution; adds per-pixel noise for stochastic fine detail (hair, freckles) separate from global attributes (pose, identity); improves FID substantially over traditional generator (StyleGAN2 later article referenced too); enables style mixing and scale-specific control; introduces perceptual path length / separability metrics for disentanglement.
- [x] hoDenoisingDiffusionProbabilistic2020 — DDPM. Read in full: diffusion models as parameterized Markov chain trained via variational bound; forward process gradually adds Gaussian noise, reverse process learned to denoise; epsilon-prediction parameterization connects to denoising score matching; simplified training objective L_simple improves sample quality; T=1000 steps; achieves CIFAR-10 FID 3.17, competitive with StyleGAN2.
- [x] songDenoisingDiffusionImplicit2022 — DDIM. Read (first ~120 lines, sufficient): generalizes DDPM to non-Markovian forward processes with same training objective, yields deterministic implicit generative process; 10-50x faster sampling wall-clock vs DDPM at similar quality; enables consistency (same initial latent -> similar high-level features across chain lengths) and meaningful latent-space interpolation.
- [x] hoClassifierFreeDiffusionGuidance2022 — CFG. Read in full (first 150 lines cover full method+results): jointly trains conditional+unconditional diffusion model in one network (randomly dropping conditioning c during training), combines score estimates at sampling time via linear extrapolation (Algorithm 2) to trade off sample fidelity vs diversity, matching classifier-guidance's FID/IS tradeoff without needing a separate classifier trained on noisy data.
- [x] rombachHighResolutionImageSynthesis2022 — LDM/Stable Diffusion. Read (first 130 lines, method fully covered): trains diffusion model in the latent space of a pretrained perceptual-compression autoencoder (KL-reg or VQ-reg) instead of pixel space, drastically cutting compute; cross-attention layers added to UNet backbone for general conditioning (text, layout, bounding boxes); achieves competitive/SOTA results on inpainting, class-conditional synthesis, text-to-image, super-resolution at much lower training/inference cost than pixel-space DMs.
- [x] podellSDXLImprovingLatent2023 — SDXL. Read (first 140 lines, method fully covered): 3x larger UNet (2.6B params) vs SD 1.x/2.x, dual text encoder (OpenCLIP ViT-bigG + CLIP ViT-L, concatenated, context dim 2048), micro-conditioning on original image size and crop coordinates to fix cropping/low-res artifacts, multi-aspect-ratio training via bucketing, separate refinement model applying SDEdit noising-denoising post-hoc; user studies show SDXL clearly outperforms SD1.5/2.1.
- [x] esserScalingRectifiedFlow2024 — SD3. Read (intro + architecture/scaling sections + text-encoder ablation, ~lines 1-140 & grepped 270-733): rectified-flow (straight-line noise-data path) formulation with improved timestep sampling (logit-normal / mode-with-heavy-tails) outperforms standard diffusion formulations at scale; introduces MM-DiT, a multimodal transformer with separate weight streams for text and image tokens plus bidirectional attention between them; uses three text encoders jointly (CLIP ViT-L/14, OpenCLIP bigG/14, T5-XXL), producing a concatenated context of 154 tokens (77 CLIP + 77 T5) in this implementation, with T5 measurably improving complex/detailed-prompt and typography performance but only a small aesthetic-quality difference when dropped; scales to 8B params, outperforms SDXL/SDXL-Turbo/DALL-E3 on prompt-following and human preference.
- [x] labsBlackForestLabs — FLUX.1, non-archival, no source file (confirmed absent from sources/ and listed as such in INDEX.md: "no source PDF found in Zotero library"). Will cite only for the fact it is a family of open-weight rectified-flow/diffusion-transformer checkpoints (FLUX.1-dev/schnell) with a larger (T5, ~256-512 token) prompt budget than SDXL's CLIP encoder, consistent with docs/synthetic-model-comparison/05_prompt-strategy-and-length-limits.md's own characterization — no specific numeric claims beyond what that internal doc states will be attributed to it.
- [x] radfordLearningTransferableVisual2021 — CLIP. Read + grep-verified (abstract, Fig.1 caption): contrastively trains an image encoder and text encoder jointly on 400M (image, text) pairs scraped from the internet to predict correct image-caption pairings, enabling zero-shot transfer; this text encoder is the conditioning backbone reused by Stable Diffusion/SDXL for cross-attention conditioning.
- [x] raffelExploringLimitsTransfer2023 — T5. Read + grep-verified (abstract, Sec. 2/2.2/2.3): casts NLP tasks into a unified text-to-text framework using a standard encoder-decoder Transformer trained on the newly introduced C4 corpus (~750GB filtered web text), scaled up to 11B parameters; base pretraining uses a maximum sequence length of 512 tokens (Sec. 2.3) — the much larger token budget (vs. CLIP's 77) exploited by its encoder when reused standalone as the text conditioning branch in FLUX/SD3.
- [x] luoLatentConsistencyModels2023 — LCM. Read in full (first 100 lines cover full method): distills a pretrained latent diffusion model (e.g. Stable Diffusion) into a consistency model operating in the same latent space, framing guided reverse diffusion as solving a probability-flow ODE and training the model to directly predict the ODE's solution; enables 2-4 step (or even 1-step) high-resolution sampling at a fraction of the training cost (~32 A100 GPU-hours) with quality competitive with standard multi-step sampling.

## sec:lit_sim_to_real (Synthetic Data for Object Detection and the Sim-to-Real Gap)
- [x] tobinDomainRandomizationTransferring2017 — Domain randomization. Read (method + related work, ~120 lines): trains an object-position detector purely on non-photorealistic simulated images with randomized textures/lighting/camera/distractors (no real pretraining), achieving 1.5cm real-world localization accuracy; core hypothesis is that with enough simulated variability the real world looks like just another random variation to the model; explicitly contrasts with photorealism-seeking approaches, which had "limited success" transferring to real robotic tasks per cited prior work.
- [x] tremblayTrainingDeepNetworks2018 — DR for detection. Read in full (through evaluation results): extends domain randomization to real-world 2D object detection (cars, KITTI benchmark) using non-photorealistic rendered cars/distractors composited over random real photo backgrounds; DR-only training is competitive with or beats a higher-fidelity synthetic dataset (Virtual KITTI) despite the latter being purpose-built to match the real test distribution (e.g. SSD: 46.3 AP@0.5 DR vs. 36.1 VKITTI); fine-tuning the DR-trained network on real data afterward outperforms training on real data alone.
- [x] heSyntheticDataGenerative2023 — "Is synthetic data...ready for image recognition?" Read (through zero-shot results + from-scratch ablation): GLIDE-generated synthetic images (with language-enhanced prompts + CLIP-based filtering) improve zero-shot CLIP classification by 4.31%/2.90% top-1 on average across 17 datasets, but when training a classifier from scratch (no CLIP initialization) on 50k synthetic ImageNet-100-class images, performance is markedly worse than real data and requires roughly 5x more synthetic images (measured via a real-data matching curve) to reach comparable accuracy — synthetic data is not as label-efficient as real data absent a strong pretrained backbone to anchor it.
- [x] trabuccoEffectiveDataAugmentation2025 — DA-Fusion. Read (through method + experimental setup): image-to-image (SDEdit-based) semantic augmentation using a pretrained Stable Diffusion checkpoint, with textual-inversion embeddings learned per class (from as few as one example) so the diffusion model can render fine-grained/novel concepts it wasn't trained on; outperforms standard geometric augmentation and prior "Real Guidance" diffusion augmentation by up to +10 points in few-shot classification, with larger gains on fine-grained concepts, but requires per-image real-image guidance (SDEdit splicing) rather than pure from-scratch generation to remain semantically anchored.
- [x] shumailovAIModelsCollapse2024 — Model collapse. Read (through language-model experiments): recursively training generative models on their own (or their predecessors') generated data causes "model collapse" — early-stage loss of low-probability tail behavior, late-stage collapse toward a low-variance/degenerate distribution — demonstrated theoretically (discrete distributions, Gaussian approximation) and empirically (GMMs, VAEs, and an OPT-125m LLM fine-tuned recursively on wikitext2, whose original-task perplexity degrades by 8-20+ points across generations); motivates guarding against uncurated, indiscriminate recursive reliance on synthetic/generated data.
- [x] aziziSyntheticDataDiffusion2023 — Synthetic diffusion data for ImageNet. Read (through CAS results): fine-tuning a large pretrained text-to-image diffusion model (Imagen) on the ImageNet training set (not merely prompting it off-the-shelf) yields class-conditional generators with SOTA FID (1.76 @256x256) and SOTA Classification Accuracy Score (69.24% @1024x256-downsampled, narrowing but not closing the gap with real-data training); explicitly notes that naive off-the-shelf-pretrained diffusion models with short CLIP-style class-name prompts produce a "very poor ImageNet classifier" and that two contemporaneous papers using pretrained (non-fine-tuned) Stable Diffusion found generated images did not improve accuracy on the clean validation set at all — domain/label alignment between generator and target task is the operative failure mode, not raw image fidelity.
